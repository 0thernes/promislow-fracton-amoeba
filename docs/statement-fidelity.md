# Statement Fidelity Audit (`docs/statement-fidelity.md`)

Playbook v1.3 Pass 2: correspondence between each prose theorem in `paper/main.tex` and its Lean 4.35.0 type in `lean/Challenge.lean` / `lean/PalomarChallenge.lean`, with the encoding choices and the differences between them.

The original version of this table stated "zero silent weakening". An independent statement audit on 2026-11-26 ([audit log](https://github.com/0thernes/0thernes-research-archive/blob/main/docs/reviews/2026-11-26-statement-audit.md)) found that several Lean statements are weaker than the paper theorems. The "Fidelity" column below records its verdicts: MATCH (the Lean statement is the paper claim), PARTIAL (the Lean statement covers part of it), MISMATCH (the headline is not what Lean proves). Paper errors are listed in [`ERRATA.md`](../ERRATA.md).
